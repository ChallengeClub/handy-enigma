# Enigma Mechanism Demo for M5Stack Tab5 / UIFlow2

M5Stack Tab5 と UIFlow2 Code Mode 向けの、**エニグマの機構説明デモ**です。

このプロジェクトは、実用的な暗号機シミュレータというより、次の点を**グラフィカルに理解すること**を重視しています。

- 右側から入力された信号が、**右ローター → 中ローター → 左ローター**へ進むこと
- 左端の **reflector（反射板）** で、固定ペア配線により別接点へ返ること
- 返ってきた信号が、**左ローター → 中ローター → 右ローター**と逆向きに戻ること
- 1文字ごとにローターが順に回転し、接続関係が変化すること

## この版の特徴

- 入力方向を **右 → 左 → 反射 → 右** に統一
- 配線アニメーションは、**線だけが順に伸びる**表現
- 反射板は、単なる折り返しではなく **固定ペア結線** として表示
- 小さい結節点の丸表示をなくし、**線の流れを見やすく**調整
- ボタン配置を説明の流れに合わせて変更
  - 左: `RESET`, `INFO`
  - 中央: `ENC`
  - 右: `KEY-`, `KEY+`
- ローター回転時のちらつきを抑えるため、**回転中のローター領域だけ再描画**

## モデルについて

このデモは、機構説明をわかりやすくするための**簡略モデル**です。

- **8接点モデル**で表現しています（A-H）
- 歴史的な 26 文字 Enigma の完全再現ではありません
- ステップ動作も、理解しやすさを優先した**簡易的な桁上がり方式**です
- reflector は**固定**で、回転しません

## ファイル構成

- `main.py`  
  Tab5 / UIFlow2 Code Mode で実行するメインスクリプト

## 使い方

1. `main.py` を UIFlow2 のプロジェクトへ配置します。
2. Tab5 上で実行します。
3. 下部ボタンで操作します。

### ボタン

- `KEY-` / `KEY+`  
  入力接点を切り替えます（A-H）

- `ENC`  
  ローターを進め、`IN` から `OUT` までの信号の流れをアニメーション表示します。

- `RESET`  
  ローター位置や表示状態を初期化し、現在のトレースを消去します。

- `INFO`  
  reflector の説明を表示します。

## 表示の見どころ

- **各ローターが独立した部品として見えること**
- **右から入って左で反射し、右に戻る流れ**が追えること
- **どの reflector ペアを通ったか**がわかること
- 1ステップごとに、**ローターが回っていることが視覚的に伝わること**

## 注意

- UIFlow2 / M5 側のフォントや描画 API の違いにより、環境によって見た目が少し変わる場合があります。
- このデモは教育用・説明用です。暗号アルゴリズムの厳密な検証用途には向いていません。
